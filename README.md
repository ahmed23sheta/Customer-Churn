# Customer-Churn
كيف يمكن للبيانات التنبؤ بمستقبل العملاء؟ 💡📊

Customer Churn Analysis & Prediction Project



سعيد بمشاركة أحد مشاريعي العملية في تحليل وتوقّع تسرب العملاء (Customer Churn)، وهو من أهم التحديات التي تواجه شركات Telecom & Subscription-Based Businesses.

الهدف لم يكن مجرد عرض أرقام، بل الإجابة على سؤالين أساسيين:

 لماذا يغادر العملاء؟ ومن هم الأكثر عرضة للمغادرة مستقبلًا؟



🔍 مراحل العمل في المشروع:

1️⃣ Data Cleaning & Transformation (ETL)

تنظيف البيانات ومعالجة القيم المفقودة باستخدام Power Query

Segmenting العملاء حسب: Age Groups، Tenure، Contract Type



2️⃣ Data Modeling & DAX

بناء نموذج بيانات احترافي

كتابة DAX Measures لحساب KPIs مثل: Churn Rate، Total & Churned Customers، Retention Metrics



3️⃣ Predictive Analytics (Machine Learning)

بناء نموذج تنبؤي لتحديد العملاء الأكثر عرضة للـ Churn

تحليل Feature Importance لتحديد أهم العوامل المؤثرة



4️⃣ Data Visualization & Dashboarding (Power BI)

تصميم Dashboard تفاعلية توضح:

Executive Overview: Churn Rate ≈ 26.8%

Customer Behavior Analysis: Age, Gender, Geography

Reasons for Churn: Competitor, Dissatisfaction, Price





📌 أهم الاستنتاجات (Insights):

1️⃣ العقد هو مفتاح الحل (Contract Type):

 أعلى نسبة تسرب للعملاء عند أصحاب العقود الشهرية (Month-to-Month). الحل: تقديم حوافز لتحويلهم لعقود سنوية لضمان ولائهم.



2️⃣ العوامل الأكثر تأثيرًا (Feature Importance):

Tenure: كلما زادت مدة الاشتراك، قلت احتمالية المغادرة

Monthly Charges: العملاء ذوي التكاليف العالية أكثر عرضة للترك

نوع الإنترنت وطريقة الدفع: مشاكل تقنية في Fiber Optic تزيد معدل التسرب



3️⃣ سبب المغادرة (Churn Reason):

 المنافسة (Competitor) هي السبب الرئيسي، بسبب عروض أفضل أو أجهزة أحدث.

 👉 Insight لقسم التسويق: مراجعة وتحسين العروض التنافسية



4️⃣ الفئة العمرية والحالة الاجتماعية:

 العملاء الأكبر سنًا (Senior Citizens) وغير المتزوجين لديهم معدل تسرب أعلى

 👉 استراتيجية: حملات تسويقية مخصصة لهذه الفئات



5️⃣ الخسائر المالية:

 إجمالي الإيرادات المفقودة بسبب الـ Churn كبير جدًا، والـ Retention أقل تكلفة من جذب عملاء جدد
